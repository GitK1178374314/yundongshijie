## 仓库当前版本（v0.4.0）的能力

| 改动 | 说明 |
|---|---|
| **断断续续轨迹** | 轨迹点位不再是等间隔的连续点链，而是带有**自然断档**：模拟真实设备采样时因信号差、口袋遮挡、系统省电等造成的丢点。整条轨迹的距离、时长、配速仍然自洽，比「每 5 秒一个点、间距均匀」的完美轨迹更接近真人跑出来的数据 |
| **界面优化** | 在 v0.3 品牌改版的基础上继续打磨界面：布局与主流程进一步优化，使用体验更顺手 |
| **学校跑区 / 打卡点识别** | 登录后自动拉取本校跑区（电子围栏）与打卡点信息，界面上直接列出可选的跑区与点位，不用手填 ID |

> 协议层、加密层与速度模型**未改动**：信封加密 / RSA 验签 / 签名盐与原版一致；
> 轨迹生成部分只新增了「断断续续」处理，其余沿用原版。

**沿用原版的功能**

- **登录**：人机验证（GT4 滑块）自动通过，本地完成
- **一键跑步**：策略 → 打卡点 → 轨迹 → 提交 → OBS 上传 → 详情回读校验
- **设备身份**：DeviceId / 安装时间 / MAC 持久化
- **AI 运动**：任务 / 自由练习双模式
- **数据与自查**：学期完成度、违规通报名单自查、排行榜
- **自动更新**：桌面端检查 / 下载 / 自替换并重启
- **主题**：多套配色，默认「晴空蓝」（v0.3 起）
- **CLI 模式**：与 GUI 同一 exe，子命令覆盖登录、跑步全链、记录、榜单、学期、违规自查，可挂青龙定时跑（详见下方「CLI 用法」）

## 数据文件（exe 同目录，绿色便携）

| 文件 | 内容 |
|---|---|
| `config.json` | 全局设置（主题、跑步参数、记住登录状态…） |
| `identity.json` | 设备指纹（DeviceId / 安装时间 / MAC），持久化，不要删 |
| `session.json` | 登录会话，失效后凭 `--remember` 的凭据自动重登 |
| `points_cache.json` | 点位缓存（300 秒，避免触发点位接口限流） |

升级只需替换 exe；**保留以上文件**，尤其不要删 `identity.json`（等于换新设备，容易触发风控提示）。

## 常见问题

- **提示未登录 / 401**：先 `login --remember`（GUI 勾选「记住密码」等价），会话失效会自动重登
- **10121 设备风险**：设备身份是持久化的，删除 `identity.json` 等于换了新设备，不要频繁删；同账号在别处（手机官方 App / 另一个程序实例）还有活跃会话时也可能触发，先把那边退出再重试
- **10603 点位限流**：点位接口 5 分钟限 3 次，程序内置缓存，正常使用不会触发
- **10600「当前学校尚未设置点位」/ 围栏为空**：该校（校区）没配跑区或打卡点，属服务端配置问题
- **11016「不在有效跑步时间内」**：计分跑有开放时段（各校不同，如 08:01–22:30），在时段内提交即可
- **人机验证失败**：自动重试（最多 3 轮），仍失败大概率是网络波动，稍后再试
- **杀软误报**：未签名编译产物可能被误报，自行判断后加白名单
